## 更新の検証方式を変更

- アプリ内更新で、GitHub Actions が発行したビルド出所証明を検証します。配布元、リリースタグ、セットアップの内容を確認できた場合のみ更新に進みます。
- 設定やタブを引き継いで更新できます。

### v1.0.2 以前から更新する場合

この版への移行は一度だけ手動で行ってください。`MD-Split-1.0.3-Setup.exe` をダウンロードし、アプリを終了してから実行してください。旧版は新しい検証方式に対応していないため、アプリ内からこの版へ自動更新することはできません。

このセットアップには Windows のコード署名（Authenticode）がありません。Microsoft Defender SmartScreen などの警告が表示されたり、Smart App Control の設定によっては実行できない場合があります。GitHub のビルド出所証明は Windows の発行元証明書とは別の仕組みです。
