## 主な変更

- **日本語・英語の切り替え**：インストーラー開始時に選択でき、初回起動時にも引き継ぎます。アプリの設定からも変更できます。初期値は Windows の表示言語に合わせ、未対応の言語は英語、表示言語を取得できない場合は日本語になります。
- **ウィンドウとタブ**：前回のウィンドウ位置・サイズを復元。タブのドラッグによる並べ替え、別ウィンドウへの切り離し、ウィンドウ間の移動に対応しました。
- **表示領域の改善**：タブが1件のときはタブ欄を初期状態で隠します。操作パネルを折りたたむとアプリ名も隠れ、編集領域を広く使えます。
- **ファイルアイコンと既定アプリ**：`.py` など対応拡張子ごとにアイコンを用意しました。`.py`・`.pyw` は既定アプリ候補に登録します。`.bat`・`.cmd`・`.ps1` などは実行を優先して候補から除外します。候補の登録だけで既定アプリは変更しません。
- **README**：画像と機能説明を更新しました。

## 更新方法

- **v1.0.3 から**：アプリ内の更新確認、または下記のセットアップから更新できます。GitHub Actions のビルド出所証明を使い、更新ファイルを検証します。
- **v1.0.2 以前から**：このページの `MD-Split-1.1.0-Setup.exe` をダウンロードし、アプリを終了して実行してください。旧版は現在の更新検証方式に対応していないため、手動での更新が必要です。

セットアップにはアプリと実行環境が含まれ、インストール時に追加のダウンロードは不要です。設定と文書の復元データは引き継ぎます。

## Windows の警告について

このセットアップには Windows のコード署名（Authenticode）がありません。Microsoft Defender SmartScreen で警告が出る場合や、Smart App Control が有効な環境で実行できない場合があります。GitHub のビルド出所証明は、更新ファイルを検証するためのもので、Windows の発行元証明書とは別です。
