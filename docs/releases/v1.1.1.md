## 主な変更

- **CSV・TSV のセル編集**：選択したセルにそのまま入力できます。Delete キーまたは Backspace キーで、単一セルや選択範囲の内容を消去できます。
- **セル選択と移動**：矢印キーでセルを移動し、Shift＋矢印キーで選択範囲を広げられます。ドラッグした範囲をハイライトし、周囲の文字が選択される問題を修正しました。ドラッグ中の自動スクロールにも対応します。
- **エクスプローラー**：種類欄には拡張子に応じたファイル種類を表示します。フォルダー内やデスクトップの何もない場所での右クリックから、新規作成を使えるようにしました。ファイルやフォルダーの右クリック項目を含め、関連メニューを初期状態で有効にします。Windows 11 では「その他のオプションを表示」の中に表示される場合があります。
- **空白・改行記号**：新しい設定では、改行・全角スペース・タブを表示し、半角スペースは表示しない設定を初期値にします。保存済みの設定は引き継ぎます。

右クリックメニューは、以前の初期設定と明示的に無効にした状態を区別できない旧バージョンからの初回更新時に有効になります。以後は設定で無効にした状態を保持します。

## 更新方法

- **v1.0.3 以降から**：アプリ内の更新確認、または下記のセットアップから更新できます。GitHub Actions のビルド出所証明を使い、更新ファイルを検証します。
- **v1.0.2 以前から**：このページの `MD-Split-1.1.1-Setup.exe` をダウンロードし、アプリを終了して実行してください。

セットアップにはアプリと実行環境が含まれ、インストール時に追加のダウンロードは不要です。設定と文書の復元データは引き継ぎます。

## Windows の警告について

このセットアップには Windows のコード署名（Authenticode）がありません。Microsoft Defender SmartScreen で警告が出る場合や、Smart App Control が有効な環境で実行できない場合があります。GitHub のビルド出所証明は、更新ファイルを検証するためのもので、Windows の発行元証明書とは別です。
