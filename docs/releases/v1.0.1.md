# MD-CSV Split Editor 1.0.1

Markdown・CSV・テキストの編集と、Discord 向けの文章の分割コピーを改善しました。

## 主な変更

- Discord 向けの分割位置を追加・削除・ドラッグ移動できるようにし、文字数の上限を超えた部分を赤枠で表示します。TXT などのテキストファイルでも分割してコピーできます。
- 上限内の文章が不要に分割される場合を改善しました。
- 検索・置換では正規表現の表記一覧と使用例を分け、連続する改行を1つにする例を追加しました。
- ファイルメニューの階層を整理し、新規作成時にファイル形式と文字コードを選択できるようにしました。
- 折りたたんだ操作欄の表示を読みやすくし、初期ウィンドウ幅を調整しました。
- TXT・LOG・Python などの起動時には、表や HTML のプレビューなどを必要になるまで読み込まないようにしました。起動時間は環境に左右され、0.5〜1秒への短縮は確認されていません。
- 各種依存関係と検証を更新しました。

## インストール・更新

Windows 10／11 の x64 向けに `MD-Split-1.0.1-Setup.exe` を用意しています。必要な .NET と固定版 WebView2 Runtime はセットアップに含まれ、セットアップ中の追加ダウンロードは不要です。

本版のインストーラーには **発行元を確認するためのコード署名がありません**。Microsoft Defender SmartScreen などで警告や「発行元が不明」と表示される場合があります。Smart App Control や組織の設定によっては実行できない場合があります。

**1.0.0 からは、このページの Setup.exe をダウンロードして手動で更新してください。** 本版にはアプリ内更新の検証用署名がないため、既存のアプリ内自動更新では検証できず、更新できません。コード署名と更新検証用署名は別のものです。

`SHA256SUMS.txt` は、ダウンロードした Setup.exe の破損を確認するためのファイルです。ハッシュだけでは発行元の本人確認はできません。
