## 主な変更

- **Markdown の改行・空行**：通常文や引用、リスト内の連続した空行をプレビューに表示し、空行をクリックして編集できるようにしました。プレビューで入力する改行やスペースの位置も改善しています。
- **プレビューのスクロール**：図を含む文書で原文を編集したとき、入力のたびにプレビューが大きく移動する問題を修正しました。
- **折りたたみの連動**：原文の「…」をダブルクリックして展開すると、プレビューと見出しナビの表示も連動します。
- **アップデート通知**：新しいバージョンの変更内容を、見出しや箇条書きなどの Markdown を展開して表示します。
- **使い方ガイド**：変更を残す場合は「名前を付けて保存」を使うよう冒頭に案内を追加しました。ヘルプから呼び出すと、元の内容の新しいガイドが開きます。

## 更新方法

- **v1.0.3 以降から**：アプリ内の更新確認、または下記のセットアップから更新できます。GitHub Actions のビルド出所証明を使い、更新ファイルを検証します。
- **v1.0.2 以前から**：このページの `MD-Split-1.1.3-Setup.exe` をダウンロードし、アプリを終了して実行してください。

セットアップにはアプリと実行環境が含まれ、インストール時に追加のダウンロードは不要です。設定と文書の復元データは引き継ぎます。

## Windows の警告について

このセットアップには Windows のコード署名（Authenticode）がありません。Microsoft Defender SmartScreen で警告が出る場合や、Smart App Control が有効な環境で実行できない場合があります。GitHub のビルド出所証明は、更新ファイルを検証するためのもので、Windows の発行元証明書とは別です。
