# MD-CSV Split Editor 1.0.2

Windows の右クリック操作と文書アイコンを改善し、さまざまなファイルを開きやすくしました。

## 主な変更

- すべてのファイルの右クリックに「MD-CSV Split Editor で開く」を追加できます。フォルダーやその背景からは、種類・文字コードを選んで新規ファイルを作成できます。追加・解除はセットアップまたは設定から行え、既定アプリは変更しません。
- アプリに関連付けた文書のアイコンに、拡張子を大きく表示します。既存の関連付けには汎用の書類アイコンが表示される場合があり、Windows の既定アプリ設定で種類ごとに選び直すと拡張子入りになります。
- 動画などのバイナリファイルを読み取り専用の16進数画面で開き、ページを切り替えずにファイル全体をスクロールできます。文字列や16進数のバイト列をファイル全体から検索でき、バイト位置も指定できます。選択・コピーは画面に読み込まれている範囲が対象です。
- Windows の関連付け候補から `.bat` を外し、旧版が登録した本アプリの候補を更新時に解除します。Windows の既定アプリ設定や他アプリの登録は変更しません。`.bat` は本アプリ内から引き続き編集できます。
- 設定画面にカテゴリ移動を追加し、Ctrl+Shift+N と新規作成ボタンの右クリックでファイル形式・文字コードを選べるようにしました。

## インストール・更新

Windows 10／11 の x64 向けに `MD-Split-1.0.2-Setup.exe` を用意しています。.NET と固定版 WebView2 Runtime を同梱し、セットアップ中の追加ダウンロードは不要です。

本版のインストーラーには **発行元を確認するためのコード署名がありません**。Microsoft Defender SmartScreen などで警告や「発行元が不明」と表示される場合があります。Smart App Control や組織の設定によっては実行できない場合があります。

**以前のバージョンからは、このページの Setup.exe をダウンロードして手動で更新してください。** 本版にはアプリ内更新の検証用署名がないため、既存のアプリ内自動更新では検証できません。Windows のコード署名と自動更新の検証用署名は別のものです。

`SHA256SUMS.txt` はダウンロードした Setup.exe の破損確認に使用できます。ハッシュだけでは発行元の本人確認にはなりません。
